# C Builder Home workflow

The Home header, output actions and three tab buttons remain fixed outside the scroll viewport; only the selected tab's content scrolls. The media folder is remembered and refreshed on opening. Narration naming, duration, manual overrides, Use Audio Name and collision-safe project/ZIP/MP4 naming are retained.

Timeline Planning has three sliders in one row: opening/ending video distribution and video-only intro duration (0 = off; max floor(narration seconds / 3)), four duration fields in one row and four sequence fields in one row. Apply validates and saves one configuration in the application config directory (c-builder-planning.json); Reroll persists the new seed. Named profiles, import/export, advanced JSON and storyboard pinning are removed from C Builder. The internal shared planner remains, using a linear distribution between endpoints. The overall video duration target and keyword shares remain in Media Selection; keyword shares are not global planning preferences.

Independent 100% image/video keyword budgets redistribute on deselection; unchecked rows are zero and disabled. Actual video duration and target constraints are reported.

Generate verifies a native project, then moves unique consumed visual sources into used/<project name>/, updates media paths and refreshes inventory. Narration and unused sources remain. Journal recovery, locks and rollback protect the move; Cancel, Retry used-media and Open in Editor remain. No GPU change is required. Windows layout and interaction require desktop acceptance.

A nonzero video-only intro requires selected eligible video sources, bypasses sequence run caps only within the prefix, preserves cooldown and source usage, and ends at the exact intro boundary. Remaining duration uses the existing distribution/ratio and resets run counters. No silent image substitution in the intro.

The optional Intro Clips Library uses the same folder/probe/cache and keyword tile workflows as normal media, with an independent video-only selection budget. Distinct non-overlapping roots are required. With intro enabled and a configured intro library, only its selected videos can fill the prefix; no silent normal-library fallback. With no intro folder, existing normal-video intro behavior is retained. Each root archives consumed sources in its own used/Project Name/ journal; the second transaction starts only after the first completes, and retry re-verifies committed paths.

Preview Plan, Preview Intro, Preview Video, Reroll share one deterministic plan keyed by profile, narration and media inventory. Preview Intro plays [0, intro), and Preview Video plays [intro, duration) (the full timeline when intro is zero). Intro remains visible but disabled at zero. Playback constructs the native timeline in memory and uses the existing frame compositor and audio clock. A bounded isolated reader pool is released before generation. The existing engine-managed audio PCM cache remains bounded and reusable; no video encoding or source relocation occurs during playback.
